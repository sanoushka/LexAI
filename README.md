# ⚖️ LexAI — AI-Powered Legal Document Analyzer

LexAI is a full-stack AI web application that allows users to upload legal documents, extract text from PDFs, generate simplified summaries, and interact with documents using intelligent question-answering.

Built with Node.js, Express, NLP pipelines, and PDF parsing.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sanoushka/LexAI.git
```

Go into the project folder:

```bash
cd LexAI
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
HF_API_KEY=your_huggingface_api_key
```

Start the server:

```bash
node server.js
```

Open in browser:

```text
http://localhost:5000
```
